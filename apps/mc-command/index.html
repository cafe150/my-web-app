Minecraft コマンドコンバーター

統合版(Bedrock)の古いコマンドを、新しい構文とブロックステートに一括変換します。

適用される変換ルール:

  • execute構文: /execute <target> <x> <y> <z> を /execute as <target> at @s positioned <x> <y> <z> run に変換。
  • detect構文: detect <x> <y> <z> <block> <data> を if block <x> <y> <z> <block> <data> に変換。
  • フラットニング対応: 羊毛、コンクリート等のAux値（例：wool 1）を最新の固有ID（例：orange_wool）に変換。
  • ハーフブロック: ハーフブロックを固有IDと上下位置プロパティ（例：wooden_slab 9 → spruce_slab ["minecraft:vertical_half"="top"]）に変換。
  • 自然ブロック: 石、土、木材などのデータ値を、最新の固有ID（例：stone 1 → granite）に変換。
