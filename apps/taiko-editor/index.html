音符入力と基本操作

                            
キャンバス上のグリッドをクリック、またはキーボードショートカットを押してリズムに合わせた音符を素早く配置できます。

                        

                    

                    

                        

                            
🎹 音符の種類とキー配置

                            

                                

                                    J または F / 1
                                    🔴 ドン（面）
                                

                                

                                    K または D / 2
                                    🔵 カッ（ふち）
                                

                                

                                    3
                                    🟠 大ドン
                                

                                

                                    4
                                    🔷 大カッ
                                

                                

                                    5 / R
                                    🟡 連打
                                

                                

                                    6
                                    🟡 大連打
                                

                                

                                    7
                                    🎈 風船連打（打数指定可）
                                

                                

                                    Space / 0
                                    ⬜ 休符 / 音符削除
                                

                            

                        

                        

                            
⚡ 効率的な配置テクニック

                            
    
                                
  • 🔄 連続配置モード (C):
    
                                    ONにすると、音符キーを押した瞬間に自動で次のグリッドへカーソルが進みます。連続入力が圧倒的に高速化します。
                                
    • 
                                
  • 🧩 テンプレートパレット:
    
                                    左サイドバーの「テンプレート」から、よく使う複合（🔴🔵、🔴🔴🔵、🔴🔵🔴など）を1クリックで配置可能です。
                                
    • 
                                
  • ↔️ 小節移動:
    
                                    キーボードの ← / → キー、または画面上部のタイムラインをクリックして自由に小節間を移動できます。
                                
    • 
                            

                        

                    

                


                
                

                    

                        
👁️

                        

                            
プレビュー機能（右サイドバー）

                            
制作中の譜面全体を俯瞰したり、出力されるTJAコードをリアルタイムに確認・コピーできます。

                        

                    

                    

                        

                            
📜 プレビュー（全体俯瞰）

                            
右サイドバーの「プレビュー」タブでは、全小節の音符配置が縦スクロールで一覧表示されます。

                            
    
                                
  • 譜面全体の密度バランスや、叩きやすさ・色の偏りを一目で確認できます。
    • 
                                
  • エディタで音符を追加・修正すると、自動でリアルタイム描画されます。
    • 
                                
  • 下部の「🗑️ データ削除」ボタンで現在の譜面を安全に初期化できます。
    • 
                            

                        

                        

                            
📄 TJAプレビュー＆サイドバー調整

                            
「TJAプレビュー」タブでは、現在編集中の譜面がTJAフォーマットのテキストとして常時生成されます。

                            
    
                                
  • 📋 コピー: 1クリックでTJAコード全体をクリップボードにコピーできます。
    • 
                                
  • 💾 ダウンロード: そのままファイルとしてダウンロード可能です。
    • 
                                
  • 📐 幅の調整: サイドバー左端の境界線をドラッグして、幅を自由に広げたり狭めたりできます。
    • 
                                
  • ▶ / ◀ 折りたたみ: 右上のボタンでワンタッチ開閉可能です。
    • 
                            

                        

                    

                


                
                

                    

                        
⚙️

                        

                            
設定項目とギミック（ソフラン・変拍子等）

                            
楽曲のメタデータ設定や、BPM変更、スクロール速度変化、ゴーゴータイムなどの多彩なギミックを小節単位で設定できます。

                        

                    

                    

                        

                            
📝 左サイドバー設定（基本情報）

                            
    
                                
  • タイトル / サブタイトル: 楽曲の曲名とサブタイトルを指定します。
    • 
                                
  • BPM: 楽曲の基本テンポ（1分間の拍数）を設定します。
    • 
                                
  • OFFSET: 音源とノーツのタイミングのズレ（秒）を微調整します（負数指定可）。
    • 
                                
  • コース・レベル: 難易度（おに・むずかしい等）と★の数を設定します。
    • 
                            

                        

                        

                            
🎯 ギミック設定（小節ごとの特殊効果）

                            
下部の「⚙ ギミック設定」ボタン（または G キー）でモーダルを開き、対象小節範囲（例: 5〜8）に適用します。

                            
    
                                
  • 🎵 BPM変化: 途中からのテンポ変更（#BPMCHANGE）を設定します。
    • 
                                
  • 📐 拍子・分割数: 3/4拍子などの変拍子や、16分・24分・32分などの音符グリッド分割数を変更します。
    • 
                                
  • 🏎 スクロール速度 (HS): 譜面の流れる速度倍率（#SCROLL）を設定します。
    • 
                                
  • 🔥 ゴーゴータイム: サビなどでスコアが増加するゴーゴーゾーン（#GOGOSTART / #GOGOEND）を指定します。
    • 
                            

                        

                    

                


                
                

                    

                        
📁

                        

                            
エクスポート・インポート・音源再生

                            
既存のTJA譜面を読み込んだり、音源ファイルと合わせて実際にテストプレイ・書き出しができます。

                        

                    

                    

                        

                            
📥 譜面・音源の読み込み（インポート）

                            
    
                                
  • 📄 TJA読込: お手持ちの .tja または .txt 譜面ファイルを読み込みます。高度なトークナイザーにより小節途中のBPM変化や変拍子も完全再現されます。
    • 
                                
  • 🎵 音源読込: 楽曲の音声ファイル（.mp3, .wav, .ogg 等）を読み込みます。
    • 
                            

                        

                        

                            
▶️ 再生と書き出し（エクスポート）

                            
    
                                
  • ▶ 再生 / 停止 (Enter): 音源と連動して譜面が自動スクロール再生されます。ソフラン（BPM変化）も正確に同期します。
    • 
                                
  • 📤 TJA出力: 編集した譜面を .tja（太鼓シミュレーター用）または .txt 形式で保存します。各種シミュレーターですぐに遊べます。
    •
