Spotify アプリの連携手順:

  1. Spotify Developer Dashboard にログインします。
  2. Create App をクリックし、アプリ名（例: SpotifyTool）を入力します。
  3. アプリ設定の Redirect URIs に上記の Redirect URI を追加して保存します（※完全一致する必要があります）。
  4. Which API/SDKs are you planning to use? で Web API にチェックを入れます。
  5. Basic Information から Client ID をコピーし、上の入力欄に貼り付けて「保存」をクリックします。
  6. 右上の「Spotifyでログイン」ボタンを押せば、あなたのアカウントの実データが読み込まれます！
💡 デモモード: Client IDが未設定の場合でも、画面上部の「デモモード」ボタンからいつでも全機能のデモデータを体感できます。
