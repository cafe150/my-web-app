BVE CSV 時間補間ツール

BVE Trainsimの駅リストCSVにおいて、未入力（空白）となっている到着・出発時刻を自動計算して補完するWebツールです。

HTML5 / CSS3 JavaScript (Vanilla JS)
  • Shift-JIS形式の解析に対応し、日本語環境のCSVでも文字化けせず読み込み可能
  • ドラッグ&ドロップによる直感的な操作と、補間箇所を視覚的に判別できるプレビュー機能
  • 15秒間隔のステップ計算ロジックにより、時刻表作成の工数を大幅に削減
アプリを開く

Minecraft コマンドコンバーター (1.16 → 1.20+)

統合版マインクラフト（Bedrock Edition）の古いコマンド構文を、最新のexecute構文やブロックステート形式へ一括変換するツールです。

HTML5 Tailwind CSS JavaScript (ES6+)
  • 旧execute/detect構文を、最新の「as at run」形式のサブコマンド構造へ正確に再構成
  • 「フラットニング」仕様に基づき、数字のデータ値（Aux値）を固有のブロックIDやステートへ自動置換
  • 正規表現を活用した高度な文字列解析により、fillやsetblock等の複数コマンドを一括処理可能
アプリを開く

PCBS 構成管理シミュレーター

「PC Building Simulator」でのPCビルドをサポートするために開発した、パーツ構成管理・チェックリストツールです。

HTML5 CSS3 (Flexbox) JavaScript
  • 「詳細選択（ドロップダウン）」と「クイックチェック（ボタン）」を組み合わせたハイブリッドなUI設計
  • 複雑なPCパーツ（CPU、GPU、メモリ4枚、ストレージ2基等）の構成を視覚的にミスなく管理可能
  • 一括リセット機能を搭載し、複数のオーダーやビルドを効率的に切り替えて作業可能
アプリを開く

懐かしの鉄道発車標（反転フラップ式）再現

かつて名古屋鉄道（名鉄）などの駅で見られた「パタパタ」こと反転フラップ式発車案内表示機を、最新のWeb技術でブラウザ上にリアルに再現しました。

HTML5 / CSS3 (3D Transforms & Animation) JavaScript (DOM & Sequential Control)
  • CSSの `perspective` と `rotateX` を駆使し、フラップが裏返る立体的な動きと、リアルな影の表現（グラデーション）を実装
  • 名鉄の表示機をオマージュした、特徴的なフォントや配色、レイアウト（種別、行き先、両数、のりば）を忠実に再現
  • JavaScriptによるタイマーとデータ配列の制御により、複数のフラップが連動してパタパタと切り替わるシーケンシャルな表示更新を実現
アプリを開く
