ブラウザ完結型 順番待ち＆POSレジ

サーバー不要でブラウザのローカルストレージとAPIを活用した、イベント・飲食店向けのリアルタイム受付・会計システムです。

HTML5 / CSS3 JavaScript (BroadcastChannel API) Web Speech API
  • バックエンド構築なしで、複数タブ（端末）間の完全リアルタイムデータ同期を実現
  • 体験イベント向けの「順番待ち受付」と「飲食店POSレジ」をポータルから切り替え可能
  • Web音声合成による自動アナウンスや、独自アルゴリズムによる待ち時間のリアルタイム算出機能
システムポータルを開く

BVE CSV 時間補間ツール

BVE Trainsimの駅リストCSVにおいて、未入力（空白）となっている到着・出発時刻を自動計算して補完するWebツールです。

HTML5 / CSS3 JavaScript (Vanilla JS)
  • Shift-JIS形式の解析に対応し、日本語環境のCSVでも文字化けせず読み込み可能
  • ドラッグ&ドロップによる直感的な操作と、補間箇所を視覚的に判別できるプレビュー機能
  • 15秒間隔のステップ計算ロジックにより、時刻表作成の工数を大幅に削減
アプリを開く

Minecraft コマンドコンバーター

統合版マインクラフト（Bedrock Edition）の古いコマンド構文を、最新のexecute構文やブロックステート形式へ一括変換するツールです。

HTML5 / Tailwind CSS JavaScript (ES6+)
  • 旧execute/detect構文を、最新の「as at run」形式のサブコマンド構造へ正確に再構成
  • 「フラットニング」仕様に基づき、数字のデータ値（Aux値）を固有のブロックIDやステートへ自動置換
アプリを開く

PCBS 構成管理シミュレーター

「PC Building Simulator」でのPCビルドをサポートするために開発した、パーツ構成管理・チェックリストツールです。

HTML5 / CSS3 (Flexbox) JavaScript
  • 「詳細選択」と「クイックチェック」を組み合わせたハイブリッドなUI設計
  • 複雑なPCパーツの構成を視覚的にミスなく管理可能

HTML5 / CSS3 (3D Transforms) JavaScript (DOM Control)
  • CSSの `perspective` と `rotateX` を駆使し、立体的な動きとリアルな影を実装
  • 名鉄の表示機をオマージュした、特徴的なフォントや配色、レイアウトを忠実に再現
